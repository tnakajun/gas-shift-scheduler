# GAS Shift Scheduler (シフト自動生成 & バリデーションエンジン)

Google スプレッドシート上で動作する、業務運用に特化したシフト自動作成・労務制約バリデーションツールです。  
`@google/clasp` を用いたローカル開発環境・Git バージョン管理・モジュール分割設計を採用しています。

---

## 📌 概要

シフト管理の現場における「組み合わせ破綻」「月またぎの過重労働」「手作業による作成コスト」を解決するために開発した Google Apps Script (GAS) ベースのソリューションです。

### 解決する課題
1. **月またぎの制約違反**: 前月末の夜勤・連勤履歴を引き継ぎ、月初1日・2日の無理なシフト割り振りを防止。
2. **労務コンプライアンスの遵守**: 最大連勤数（デフォルト5日）、夜勤後のインターバル（明＋公休）、月間公休数の均等化を自動判定。
3. **運用柔軟性**: 1つのツールで「平日日中」「日中365日」「24時間365日（交代制）」の3モードに即座に対応。

## ✨ 主な機能

### 1. 3つの運用モード対応
| モード名 | 対象日 | シフト種別 | 主なユースケース |
| :--- | :--- | :--- | :--- |
| **WEEKDAY_ONLY** | 平日のみ | 日勤 / 祝休 | バックオフィス、カスタマーサポート（平日型） |
| **DAY_365** | 全日 | 日勤 / 公休 | 店舗、クリニック、土日稼働コールセンター |
| **FULL_24_365** | 全日 | 日勤 / 夜勤 / 明 / 公休 | 医療機関、インフラ監視運用、警備、介護施設 |

### 2. 前月データ連携（月またぎ連勤・夜勤の自動引き継ぎ）
* 前月シートの末尾データを自動スキャン。
* 前月末が「夜勤」の場合は当月1日を強制的に「明」に設定。
* 月末からの連勤カウントを引き継ぎ、月初早々に公休を割り振る安全設計。

### 3. ルールベース生成 + バリデーションエンジン
生成後、以下の条件を自動検証し、違反箇所をスプレッドシート上で警告（背景色変更 & コメント付与）します。
* ❌ 6連勤以上の検知
* ❌ 夜勤の翌日に「日勤」または「夜勤」が入る連続勤務
* ❌ 夜勤明け（明）の翌日に「公休」が確保されていないパターン
* ❌ 各日の必要最低稼働人数の不足

## 🚀 クイックスタート (セットアップ手順)

### 前提条件
* Node.js (v18 以上推奨)
* Google アカウント

### 1. リポジトリのクローンと依存パッケージのインストール
```bash
git clone https://github.com/your-username/gas-shift-scheduler.git
cd gas-shift-scheduler
npm install
```

### 2. clasp のログインとプロジェクト連携
```bash
# Googleアカウントでログイン
npx clasp login

# 既存のスプレッドシートと連携する場合 (Script IDを指定)
npx clasp clone <YOUR_SCRIPT_ID> --rootDir ./src

# または新規スタンドアロンスクリプトを作成
npx clasp create --title "GAS-Shift-Scheduler" --type sheets --rootDir ./src
```

### 3. コードのプッシュ (デプロイ)
```bash
# srcディレクトリ配下のコードをGASへ反映
npm run push
# または
npx clasp push
```

## 📊 スプレッドシート側の構成例

### 設定シート (`Config`)
| パラメータ | 設定値 | 説明 |
| :--- | :--- | :--- |
| 対象年月 | `2026-09` | 作成したい年月 |
| 運用モード | `FULL_24_365` | `WEEKDAY_ONLY` / `DAY_365` / `FULL_24_365` |
| 最大許容連勤数 | `5` | これを超える連勤をエラー検知 |
| 前月シート名 | `2026_08` | 引き継ぎ元のシート名 |

### 操作方法
1. スプレッドシート上部メニューに表示される **「⚡ シフト管理」** をクリック。
2. **「当月シフトを自動生成」** を実行。
3. 生成完了後、自動でバリデーションが走り、問題があるセルがハイライトされます。
